## 0. 最重要的规则（用户 2026-09-14 锁定，违反即返工）

0. **两个独立动作，必须分清（用户强调）**：
   - **发票回写** = 从发票获取**准确信息**（产品名/品名/供应商/条码/单价/税率）写回库存表。发票是权威信息源；命中才回写，不命中=死库存。
   - **新旧对比回写** = 用户清点出的**新区行（384-471）基本都是旧区（1-383）已有的同物料**（401=114、393=124、418=89、388=97）→ 确认同物料后，**把新区行数据回写到旧区对应行**（状态/品名/分类/图片统一），新区原行按规则删除/保留。**这不是查发票，是合并重复清点。**
   - 执行顺序：识别物料 → 发票回写（决定命中/死库存）→ 新旧对比（新区行↔旧区行合并）→ 一致性校验（同物料两行状态一致）。

1. **条码规则**：非 PEN 开头条码（tony/WFDRGMA/EM4002/纯数字等）= **死库存**；PEN 开头 = **待定**。不要因发票里有同规格行就改判命中。
2. **图片规则**：追加区行图片 = 同物料旧区行的图，**映射必须用「产品名+尺寸+品名」三列核对**（必要时识图），严禁沿用历史猜测。链接格式统一 `=HYPERLINK("D:\sara\库存管理\图片\W1-SHELF3\<n>.jpg","photo link")`，**单反斜杠**。
3. **字典规则**：每次匹配前先完善 `翻译字典.xlsx`；匹配用「词组本身 + 词组每个单词 + 缩写」全量查发票。字典含 5 列（原文/扩展名/中文/同义词/**图片**）。
4. **写回规则**：命中替换原位置（图片用老数据，其余用新数据）；未命中**淡蓝 DDEBF7** + 必写原因（型号/尺寸/材质/全部关键词搜不到）；已命中的下方追加行删除，只留未命中。
5. **分类规则**：紧固件命中 = CONSUMABLE；未命中 = dead inventory；命中但非紧固件 = 留空。
6. **材质规则**：同基材（304↔316↔不锈钢镀锌↔不镀锌）视为命中；不同基材（黄铜 vs 不锈钢）不命中。手工测量误差不大视为命中。
7. **高置信才写**；不确定先空着留给用户。每次改主表前先备份。
8. **识图前置 + 图片预处理（用户 2026-09-15 新增，违反即返工）**：**任何行的品类/族判定必须先看该行实拍图**，禁止按行号/族清单批量假设（教训：73-79 误判法兰，实际为手轮×3/圆筒/方形法兰/带法兰壳体/ARANCI 扳手）。识图前先预处理：任一边超 4000px 的图片先用 PIL 缩到 ≤2000px（存 `C:\Users\85345\Downloads\img_resized\`，quality=88）再 Read；**禁止因图超尺寸被过滤而跳过识图**。
