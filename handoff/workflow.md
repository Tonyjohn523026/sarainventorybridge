## 阶段 3：匹配核销（核心）

### 两个独立动作，先分清，再执行（用户明确 2026-09-14）

**① 发票回写（获取准确信息）**：目标是**从发票拿准确数据**。对任何待核销行（新旧区都适用），到发票/近3年文件检索：命中 → 把发票的准确产品名/品名/供应商/条码/单价/税率/数量写回；不命中 → 标死库存+原因。**发票是权威信息源，回写=拿准确信息。**

**② 新旧对比回写（合并新区与旧区）**：用户清点出的**新区行（384-471）基本上都是旧区（1-383）已有的同物料**（如 401=114、393=124、418=89、388=97）。新区行与旧区行确认同一物料后，**把新区行数据回写到旧区对应行**（状态/品名/分类/图片统一），新区行按规则处理（命中→替换原位置后下方删除；未命中→保留在下方或删除，听用户指令）。**新旧对比=合并重复清点，不是查发票。**

> 执行顺序：先识别物料 → **发票回写**（决定命中/死库存）→ **新旧对比**（新区行↔旧区行合并回写）→ 一致性校验（同物料新旧两行状态必须一致）。

1. **锁定目标行**：按用户点名（如追加区无图部分、某段行号）或筛空条码/空品名行。
2. **识别物料**：Product Name + size + 品名三列联合看（发票把规格写在品名里、人工分列写），**有图必识图**（客观，图文/型号对不上要提醒用户校对）。**禁止按行号/族假设批量判定品类——每行品类判定必须先看该行实拍图**（读图前先过阶段 0 图片预处理）。
3. **发票回写检索**（`invoice_full_dump.txt` 快速定位 → 回 `物料发票表` 原文核验）：
   - 紧固件：头型（SVASATA 沉头/CROCE 十字/PIATTA 盘头/TONDA 圆头/BRUGOLA 内六角/T.E. 外六角）+ M×L + 材质。
   - 管件：同族关键词 + 尺寸；宁缺毋滥。
4. **命中判定**（决定是否发票回写）：
   - 同基材（304↔316↔不锈钢镀锌↔不镀锌）→ 命中；不同基材（黄铜 vs 不锈钢）→ 不命中。
   - 手工测量误差不大 → 视为命中（先汇报误差，用户认可后写）。
   - 厂商写简化（盘头十字 vs 只写盘头/只写十字；沉头十字 vs 只写沉头）→ 放宽算命中。
   - **条码规则（2026-09-19 更新）**：已取消「非 PEN=死库存」。条码前缀不单独定性；以识图+规格+发票全量检索为准。
5. **新旧对比回写**：新区行与旧区行按（品名族+规格+材质）确认同物料 → 新区行数据回写到旧区行，新区行按命中/未命中规则处理；**不在新区 7 大种类（管卡/管箍/弯头/三通/对丝/短外丝/异径）的旧区物料不精细对比**，按族粗处理。
6. **未命中分类原因**（写中文品名）：型号对不上 / 尺寸对不上 / 材质对不上 / 发票中所有关键词都搜不到——四选一或组合。
7. **输出匹配清单给用户**（尤其管件/密封/图片复用），用户说「写入/覆盖/确认」才动主文件。

## 高精度识图标准（2026-09-18 用户锁定 · 违反即返工）

> 起因：SHELF3 NO209-217 共 9 行被拼图阶段误判为 CARTELLA 焊接底座，实为 90° 不锈钢弯头（GOMITO，EN 10253-4 无缝），品名/分类系统性错误漏检。用户确认：**此后所有货柜（含已完成的 SHELF4/SHELF5）一律按本标准重核与执行**。

### 1. 三重比对（每行必做）
对每个有图行，三个信息源必须一致：
- **① 图片实物形状**：先回答"图片里是什么"（L 形弯头 / 环形焊接底座 / T 形三通 / 直管段 / 法兰…），记录形状描述；
- **② 图上刻字/印字/标签**：逐字读取（如 `EN 10253-4`、`26,9X3,0`、`304L`），记录原文；
- **③ 主表品名 + 尺寸列**：与①②比对，任一不符即问题行；**不得以"图片对应该行号"直接判对**。

### 2. 拼图仅定位，品类判定必须原图
- 拼图（多格缩略图）只允许确认「图 → NO 行号」的归属；
- **品类判定一律打开原图逐张看**（超 4000px 先按阶段 0 缩到 ≤2000px）；
- 禁止仅凭拼图小图轮廓 + 品名标签推断品类，禁止先入为主接受主表品名。

### 3. 同族聚类交叉验证（防批量漏检）
- 同类词条（CARTELLA / GOMITO / CURVA / TEE / RACCORDO / MANICOTTO / TAPPO…）的全部行聚在一起整体检查；
- **一个族内出现形状明显不同的实物 = 族内品类判定可疑，须逐张复核**；
- 参考做法：SHELF3 的 9 行弯头应被「焊接底座族里出现 9 个 L 形件」这条规则拦下。

### 4. 逐行证据留痕（写回 bridge）
- 交检时逐行给出：`NO｜图片形状｜刻字/印字原文｜主表品名｜结论（一致/不符→改法）`；
- 禁止只写「全对 / 命中」这类无法验证的结论；Cursor 可抽查任意一行复核。

### 5. 主表品名与字典词条联动
- 主表品名必须能落到字典实际词条（GOMITO 就是 GOMITO，不得混成 CARTELLA）；
- 落不上的先补字典再核销；字典词条 E 列图片须与实物**类型**一致（形状类，非仅行号对应）。

### 6. 已核销货柜专项复核
- SHELF4 / SHELF5（含其余已完成货柜）须按本标准做**品类一致性专项重核**：逐张原图比对形状/刻字/品名，重点优先 CARTELLA、GOMITO/CURVA、TEE、RACCORDO、MANICOTTO 等易混族；
- 重核结果逐行留痕到 bridge（同第 4 条格式）；发现错误行按批次规则交 `plan_submitted` 修正。
